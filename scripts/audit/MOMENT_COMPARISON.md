## Mathematical Background

### Implementation A: Null-Space Projection

Projects Q onto the null space of L and checks definiteness:

```
kernel = null_space(L.reshape(1, -1))  # K-1 dimensional
Q_proj = kernel.T @ Q @ kernel
unreachable = all(eigvals(Q_proj) > 0) or all(eigvals(Q_proj) < 0)
```

### Implementation B: X-Sweep

Sweeps over x values to find definite M = Q + x·LL^T:

```
for x in linspace(-100, 100, 2001):
    M = Q + x * L_outer
    if all(eigvals(M) > 0) or all(eigvals(M) < 0):
        return True
return False
```

### Mathematical Equivalence

Both approaches test the same criterion but differ in numerical robustness:
- **Null-space**: Direct computation, exact for rank-1 L
- **X-sweep**: Depends on range and granularity of x values

## Conclusion

### Key Findings

1. **Implementations are effectively equivalent** (>99% agreement)
2. **Disagreements are rare** and occur only at minimal K=3
3. **Null-space is 24-65x faster** depending on K
4. **Neither has false positives** on provably reachable targets

### Root Cause of Disagreements

The x-sweep uses a finite range [-100, 100] while the null-space projection is mathematically exact. When the optimal x value lies outside this range, x-sweep may miss it.

### Recommendation

**Use the null-space approach** in all production code:
- Faster by 1-2 orders of magnitude
- Mathematically exact (no range limitations)
- Same false positive rate (0%)

The x-sweep approach can be kept as a validation tool but should not be used in production sweeps.

## Implementation Reference

### Null-Space (Recommended)

```python
def moment_nullspace(psi, phi, hams):
    K = len(hams)
    L = np.array([qutip.expect(H, phi) - qutip.expect(H, psi) for H in hams])

    kernel = null_space(L.reshape(1, -1))
    if kernel.size == 0:
        return False

    Q = np.zeros((K, K))
    for i in range(K):
        for j in range(K):
            anticomm = (hams[i] * hams[j] + hams[j] * hams[i]) / 2
            Q[i, j] = qutip.expect(anticomm, phi) - qutip.expect(anticomm, psi)

    Q_proj = kernel.T @ Q @ kernel
    eigvals = np.linalg.eigvalsh(Q_proj)
    return bool(np.all(eigvals > 1e-10) or np.all(eigvals < -1e-10))
```
